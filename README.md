# ディレクションシステムβ

Webディレクションの段取り、合意形成、意思決定、公開前チェックまでを、チームの運用ルール一式にまとめたものです。
一般社団法人ディレクションサポート協会（DiSA）が制作しています。

「だれが・何を・いつまでに・どう進めるか」をチームで同じように進められる状態にすることが目的です。
説明はすべてMarkdownで書いてあり、人もAIもそのまま読めます。

**Web版:** https://drsp.cc/direction.html

## 使い方

1. 右上の **Use this template** から、自分のチーム用のリポジトリを作ります
2. `templates/` のファイルを、プロジェクトに合わせて書き換えます
3. 進め方を変えたら、その場でこのリポジトリに書き足します

`docs/` はルールの説明、`templates/` はそのまま使う書式です。

## 中身

### docs（ルールの説明）

| ファイル | 中身 |
|---|---|
| [01_準備と設計.md](docs/01_準備と設計.md) | プロジェクトが始まる前にやること。優先順位の合意、工程と役割、最初に決める7分野のルール、キックオフで確認する14項目 |
| [02_進行と運用.md](docs/02_進行と運用.md) | プロジェクトが始まってからやること。運用ルール、定番の進行手順、Do & Don't、よくある失敗と対策 |
| [03_記法ルール.md](docs/03_記法ルール.md) | タスク・書類・チャットリアクションの共通記号 |
